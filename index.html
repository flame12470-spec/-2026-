สร้างโปรเจกต์ใหม่

ตั้งค่าฐานข้อมูลของคุณ (Firebase)

กรอกค่า config จากโปรเจกต์ Firebase ของคุณเอง (Firebase Console → Project settings → Your apps → SDK setup and configuration) ค่าจะถูกบันทึกไว้ในเบราว์เซอร์นี้เท่านั้น ไม่มีการส่งไปที่อื่น

โค้ดเชื่อมต่อฐานข้อมูลสำหรับเว็บไซต์อื่น

คัดลอกโค้ดด้านล่างไปวางในเว็บไซต์อื่นของคุณ (ก่อน </body>) เพื่อให้เว็บนั้นบันทึก/อ่านข้อมูลลงฐานข้อมูลเดียวกัน โดยจะเก็บแยกเป็นชุดข้อมูลของโปรเจกต์นี้โดยเฉพาะ

แก้ไขชื่อตรงนี้ได้ตามต้องการ (ตัวอักษร/ตัวเลข/ขีดกลาง) — พิมพ์เสร็จระบบจะเขียนโค้ดด้านล่างให้ใหม่ทันทีอัตโนมัติ ไม่ต้องแก้โค้ดเอง
⚠️ สำคัญ: โค้ดนี้ทำให้เว็บไซต์อื่นเขียนข้อมูลเข้าฐานข้อมูลของคุณได้โดยไม่ต้องล็อกอิน ก่อนใช้งานจริงควรไปตั้งค่า Firestore Security Rules ใน Firebase Console ให้จำกัดสิทธิ์การเขียน/อ่านเฉพาะ collection external_data เท่านั้น (ไม่เช่นนั้นใครก็ตามที่มีโค้ดนี้จะเขียนข้อมูลเข้ามาได้) — หลังคัดลอกโค้ด รายการเว็บไซต์นี้จะไปโผล่ในเมนู 🗄️ ฐานข้อมูล ที่ navbar ให้อัตโนมัติ ซึ่งคุณสามารถดู/แก้ไข/ลบข้อมูล และระงับการใช้งานเว็บนี้ได้จากที่นั่น

แก้ไขข้อมูล (JSON)

แก้ไขค่าด้านล่างแล้วกดบันทึก ต้องเป็นรูปแบบ JSON ที่ถูกต้อง

เผยแพร่โปรเจกต์เป็นเว็บไซต์

เผยแพร่โปรเจกต์นี้ให้มีลิงก์สาธารณะ ใครก็เปิดดูได้ทันทีโดยไม่ต้องล็อกอิน

⚠️ ต้องตั้งค่า Firestore Security Rules ให้ collection published อ่านได้แบบสาธารณะ (เช่น allow read: if true;) แต่จำกัดการเขียน/ลบเฉพาะเจ้าของเท่านั้น ก่อนใช้งานจริง ไม่เช่นนั้นลิงก์จะเปิดไม่ขึ้นหรือใครก็แก้ไขได้
